Triaxial test on foliated rock: a step-by-step guide

How the PFC3D model is built, how the foliation plane is given its strength, and how to read the result. No lab data is used here.

1. The five scripts

Click a step. Each script saves the model state, and the next one restores it.

2. Stress on the foliation plane

Move the sliders. The plane slides when the shear stress reaches c + sn tan(phi). The page computes the deviator at which this happens.

sn = sigma3 + D cos^2(dip), tau = D sin(dip) cos(dip), and at the peak D = (c + sigma3 tan(phi)) / (sin(dip) cos(dip) - cos^2(dip) tan(phi)).

3. Cohesion of one specimen

One test gives one point (sn, tau), so only one parameter per specimen can be set. Keep phi and compute c_i = tau - sn tan(phi). Move the sliders to place the point.

4. The smooth-joint contact law

Each plane contact is bonded until the shear force reaches the Coulomb limit. Then it keeps only friction.

If the normal stress becomes tensile and larger than sj_ten, the bond breaks in tension and no shear is carried.

5. Run it yourself

The Python tools run on the synthetic data without PFC. See the README and the notebooks in notebooks/.
